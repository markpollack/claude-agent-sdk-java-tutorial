# Module 05: Message Types

Understanding the message and content block type hierarchy. Learn the four message types (User, Assistant, System, Result) and pattern matching with sealed interfaces.

## Documentation

This module is self-contained: read the source in `src/main/java`, then run it below.
For the SDK's canonical documentation see
https://lab.pollack.ai/projects/claude-agent-sdk

## Running

```bash
mvn compile exec:java -pl module-05-message-types
```
