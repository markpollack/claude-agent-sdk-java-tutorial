# Module 14: Permission Callbacks

Implementing dynamic tool permission decisions with hooks. Learn `HookRegistry.registerPreToolUse()` for runtime permission control.

## Documentation

This module is self-contained: read the source in `src/main/java`, then run it below.
For the SDK's canonical documentation see
https://lab.pollack.ai/projects/claude-agent-sdk

## Running

```bash
mvn compile exec:java -pl module-14-permission-callbacks
```
