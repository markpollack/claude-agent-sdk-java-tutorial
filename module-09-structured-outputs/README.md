# Module 09: Structured Outputs

Getting Claude to return structured JSON responses. Learn `JsonSchema` to define output structure and parse JSON responses with Jackson.

## Documentation

This module is self-contained: read the source in `src/main/java`, then run it below.
For the SDK's canonical documentation see
https://lab.pollack.ai/projects/claude-agent-sdk

## Running

```bash
mvn compile exec:java -pl module-09-structured-outputs
```
