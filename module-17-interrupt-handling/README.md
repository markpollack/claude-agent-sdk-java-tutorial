# Module 17: Interrupt Handling

Graceful shutdown during Claude execution. Learn JVM shutdown hooks, `client.interrupt()`, and proper resource cleanup.

## Documentation

This module is self-contained: read the source in `src/main/java`, then run it below.
For the SDK's canonical documentation see
https://lab.pollack.ai/projects/claude-agent-sdk

## Running

```bash
mvn compile exec:java -pl module-17-interrupt-handling
```
