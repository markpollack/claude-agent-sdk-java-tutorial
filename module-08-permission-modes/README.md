# Module 08: Permission Modes

Controlling how Claude handles tool execution permissions. Learn the four permission modes (DEFAULT, ACCEPT_EDITS, PLAN, BYPASS_PERMISSIONS) and when to use each.

## Documentation

This module is self-contained: read the source in `src/main/java`, then run it below.
For the SDK's canonical documentation see
https://lab.pollack.ai/projects/claude-agent-sdk

## Running

```bash
mvn compile exec:java -pl module-08-permission-modes
```
