# Module 21: Subagents Introduction

Defining and spawning custom subagents. Learn agent JSON configuration and the `--agents` CLI option via CLIOptions.

## Documentation

This module is self-contained: read the source in `src/main/java`, then run it below.
For the SDK's canonical documentation see
https://lab.pollack.ai/projects/claude-agent-sdk

## Running

```bash
mvn compile exec:java -pl module-21-subagents-intro
```
