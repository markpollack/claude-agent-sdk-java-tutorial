# Module 20: MCP with Hooks

Combining MCP servers with hooks for custom behavior. Learn to intercept MCP tool calls and build custom tool behavior.

## Documentation

This module is self-contained: read the source in `src/main/java`, then run it below.
For the SDK's canonical documentation see
https://lab.pollack.ai/projects/claude-agent-sdk

## Running

```bash
mvn compile exec:java -pl module-20-mcp-custom-tools
```
