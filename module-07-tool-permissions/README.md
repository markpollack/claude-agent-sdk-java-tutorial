# Module 07: Tool Permissions

Controlling which tools Claude can use. Learn `allowedTools` to whitelist tools and `disallowedTools` to blacklist specific tools.

## Documentation

This module is self-contained: read the source in `src/main/java`, then run it below.
For the SDK's canonical documentation see
https://lab.pollack.ai/projects/claude-agent-sdk

## Running

```bash
mvn compile exec:java -pl module-07-tool-permissions
```
