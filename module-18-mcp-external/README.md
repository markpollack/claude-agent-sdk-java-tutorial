# Module 18: MCP External Servers

Connecting to external MCP servers. Learn `McpStdioServerConfig`, MCP tool naming conventions, and pre-approving MCP tools.

## Documentation

This module is self-contained: read the source in `src/main/java`, then run it below.
For the SDK's canonical documentation see
https://lab.pollack.ai/projects/claude-agent-sdk

## Running

```bash
mvn compile exec:java -pl module-18-mcp-external
```
